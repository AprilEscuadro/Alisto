# 🩺 ALISTO

**Offline Emergency Response System for the Elderly**

---

## 📖 About

ALISTO is an offline emergency response system designed to help elderly individuals during emergencies. It detects emergency voice commands in Cebuano (Bisaya) without requiring an internet connection and sends alerts to registered family members or responders through the mobile application.

---

## ✨ Features

- 🎤 Offline voice detection
- 🧠 Emergency phrase recognition
- 📱 Android mobile application
- 🚨 Emergency alert notifications
- 👥 Multiple emergency contacts
- 📜 Alert history
- ❌ 5-second false alarm cancellation

---

## 🚨 Emergency Detection Flow

1. ALISTO continuously listens for emergency voice commands.
2. The AI analyzes the detected speech locally.
3. If an emergency phrase is recognized, a 5-second cancellation timer starts.
4. If not canceled, the device sends an emergency alert.
5. Registered contacts receive the notification.
6. The emergency is saved in the alert history.
